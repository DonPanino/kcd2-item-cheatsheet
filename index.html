Item field guide

An item is one XML tag in Libs/Tables/item/item.xml and the item__*.xml files next to it. Each attribute below is one value you can change. The numbers are what the shipped files actually use. item.xsd does not set a minimum or a maximum.

Changing an item

  1. Copy the whole tag into mods/<modid>/Data/Libs/Tables/item/item__<modid>.xml and keep Id and Name.
  2. Change the values you care about. Combat and charisma numbers in the file are the values at MaxQuality.
  3. Pack with ./mod pack <modid> --install.

Item types

Choose a type to keep only the attributes that belong on it. Choose it again to show every attribute.
