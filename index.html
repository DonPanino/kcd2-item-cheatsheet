Kingdom Come: Deliverance 2

Item cheat sheet

This is a field guide for Kingdom Come: Deliverance 2 item rows. An item is one XML tag inside Libs/Tables/item/item.xml and the item__*.xml files next to it. Each tag is an item type, and each attribute on that tag is one value you can change.

How to read this

  • R Required by item.xsd
  • o Optional
  • Does not apply

The allowed attributes come from Libs/Tables/item/item.xsd. A short meaning is written under each name below. The big table at the end shows which item types accept each attribute. R means the schema requires it. o means you can set it or leave it off. · means that type does not have that attribute.

Quality on the item card

Combat, charisma, and the attack number in the file are the values at MaxQuality. A copy that spawned at a lower quality shows a smaller number in the inventory.

Changing an item

  1. 1

    Copy the whole tag

    Copy its whole tag into this file, and keep Id and Name.

    mods/<modid>/Data/Libs/Tables/item/item__<modid>.xml
  2. 2

    Change the numbers

    Change the numbers you care about.

  3. 3

    Pack and install

    Pack with this command.

    ./mod pack <modid> --install
